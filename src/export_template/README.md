# Reconstructed frontend

TanStack Start with physical file routes and Bun. Read [EDITING.md](EDITING.md) for the route map, edit locations, and remaining reconstruction debt.

```sh
bun install --frozen-lockfile
bun run build
bun run check
bun start
```

For development: `bun run dev`. Bun 1.4.4 is the pinned toolchain.

Routes delegate to feature pages. Captured CSS and recovered client programs remain explicitly marked compatibility source. They are not an authored Base UI application or a unified design system. Adding whitespace to deployed JavaScript does not restore original names, types, feature boundaries, or hooks.

The export command does not install dependencies or verify runtime behavior. See `.mochi/export.json` for provenance and limitations, and `.mochi/style-audit.json` for observed style values. These reports and build output are ignored; application source and required public assets are not.
